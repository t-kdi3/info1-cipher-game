# 情報Ⅰ 暗号解読チャレンジ

クラスと出席番号を入力し、40分以内に暗号問題を解くブラウザーゲームです。ランキング画面には全問正解タイム、問題別の最速解答タイム、クラス別の平均回答完了数を表示します。

- クラス：1-1〜1-8
- 0：例題は練習用で、クリア条件と平均正答数の対象外
- 集計対象：1〜6、および7-1・7-2の計8問
- 問題と正答は `js/puzzles.js` で設定
- ランキング記録はGoogle Apps Script（GAS）API経由

## ローカルで実行

HTMLを直接開くのではなく、ローカルHTTPサーバーから開いてください（`localStorage` を安定して使うため）。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。ランキング／共有記録を使うには、次の手順でGAS APIを設定してください。

## 問題を設定する

`js/puzzles.js` の各課題の `question` と `answers` を編集します。`answers` は正答文字列の配列です。別表記を許可する場合は候補を追加します。画像を出題する場合は `image` にプロジェクト内の画像パスを指定します。`downloads` には追加のダウンロードリンクを指定できます。回答の比較前に前後の空白を除き、Unicode NFKC正規化を行います。

```js
{
    id: "caesar",
    title: "2：シーザー暗号",
    section: "課題",
    counted: true,
    question: "問題文を記入",
    answers: ["正答", "別表記"]
}
```

`question` または `answers` が未設定の課題は「準備中」と表示され、回答欄は使えません。例題は `counted: false` のままにしてください。

## Googleフォームの回答先とGAS APIを接続する

Googleフォームの**回答**タブから回答先スプレッドシートを作成します。そのスプレッドシートを開き、**拡張機能 → Apps Script** からスクリプトを作成します。プロジェクトの `Code.gs` に [apps-script/Code.gs](apps-script/Code.gs) の内容を貼り付けて保存してください。このスクリプトは、フォーム回答とは別の `GameResults` シートを自動作成し、ゲーム結果を記録します。フォームの設問をゲーム用に変更したり、フォームの投稿URLをゲームに設定したりする必要はありません。

Apps Scriptの**プロジェクトの設定 → スクリプト プロパティ**に次を追加します。

- プロパティ：`RESULTS_SPREADSHEET_ID`
- 値：回答先スプレッドシートのURLに含まれる `/d/` と `/edit` の間のID

Apps Scriptで **デプロイ → 新しいデプロイ → ウェブアプリ** を選び、次のように設定します。

- 次のユーザーとして実行：自分
- アクセスできるユーザー：利用環境に合わせて設定（匿名ユーザーがゲームを使う場合は全員がアクセス可能な公開設定が必要）
- デプロイ後に表示されるウェブアプリURLをコピー

初回はスプレッドシートへのアクセス権限を許可してください。コードを変更して再デプロイする場合は、既存デプロイを編集して新しいバージョンを選びます。ウェブアプリURLを `js/config.js` の `GAME_API_URL` に設定します。末尾が `/exec` のURLを使い、`/dev` のテスト用URLは使わないでください。

Apps Scriptのコードを更新した場合、エディタで保存するだけでは公開中のウェブアプリに反映されません。**デプロイ → デプロイを管理 → 編集（鉛筆） → バージョン：新バージョン → デプロイ**を実行してください。既存のウェブアプリURLは通常そのまま使えます。

公開ウェブアプリは、URLを知る人から結果登録リクエストを受け取れます。URLを公開範囲の狭い場所で管理し、スプレッドシート自体は共有公開しないでください。より強い不正投稿対策が必要な場合は、利用者認証やアクセス制御を追加してください。

APIは次の仕様で動作します。

### 記録（POST）

```json
{
  "type": "result",
  "className": "1-1",
  "studentNumber": "12",
  "solvedCount": 5,
  "puzzleTimes": {
    "acrostic": 31,
    "caesar": 74
  },
  "totalCount": 8,
  "status": "timeout",
  "elapsedSeconds": 2400,
  "startedAt": "2026-01-01T10:00:00.000Z",
  "finishedAt": "2026-01-01T10:40:00.000Z"
}
```

保存成功時は `{"ok":true}` を返します。タイムアップ・全問クリアのどちらも結果画面から自動送信し、送信に失敗した場合は画面のボタンから再送信できます。

### ランキングとクラス平均（GET）

```json
{
  "rankings": [
    { "className": "1-1", "studentNumber": "12", "elapsedSeconds": 812 }
  ],
  "classAverages": [
    { "className": "1-1", "averageSolved": 5.25, "participantCount": 4 }
  ],
  "puzzleRankings": [
    { "puzzleId": "acrostic", "className": "1-1", "studentNumber": "12", "elapsedSeconds": 31 }
  ]
}
```

`puzzleTimes` は各問題に正解した時点の、ゲーム開始からの経過秒数です。ランキング画面では全問クリア (`status: "complete"`) の記録をタイム順で表示します。クラス平均は参加者ごとの回答完了数を平均し、全クラス分を返します。全問クリアした参加者は8問回答完了として平均に含めます。`puzzleRankings` は集計対象の問題ごとに最小の解答経過秒数と、その記録のクラス・出席番号を返します。記録がない場合は空配列を返してください。

ブラウザーからGASへアクセスできるよう、ウェブアプリの公開設定とクロスオリジンアクセスも確認してください。URL未設定時は、共有記録を利用できないことを画面に表示します。
